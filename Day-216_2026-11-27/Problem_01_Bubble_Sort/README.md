# Problem 1: Bubble Sort in Ascending Order

## Problem
Sort `n` integers from smallest to largest using Bubble Sort.

## Concept
Compare adjacent values and swap them if they are out of order. After each pass, the largest remaining value reaches the end.

## Example
```text
Input:
5
5 1 4 2 8
Output:
Sorted array: 1 2 4 5 8
```

## Complexity
Worst/average time O(n^2); best time O(n) with early stopping; extra space O(1).
