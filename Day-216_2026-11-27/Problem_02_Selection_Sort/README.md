# Problem 2: Selection Sort in Ascending Order

## Problem
Sort `n` integers in ascending order using Selection Sort.

## Concept
For each position, find the smallest value in the unsorted suffix and swap it into that position.

## Example
```text
Input:
5
29 10 14 37 13
Output:
Sorted array: 10 13 14 29 37
```

## Complexity
Time O(n^2) in all cases; extra space O(1).
