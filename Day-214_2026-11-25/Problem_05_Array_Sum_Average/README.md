# Problem 5: Array Sum and Average

## Problem
Given `n` integers, calculate their sum and arithmetic average.

## Concept
Add every element to a running total. Divide the total by `n` using floating-point division to get the average.

## Example
```text
Input:
4
10 20 30 40
Output:
Sum: 100
Average: 25.00
```

## Complexity
Time O(n); extra space O(1), excluding the input array.
