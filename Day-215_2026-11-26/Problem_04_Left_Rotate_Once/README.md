# Problem 4: Left Rotate an Array by One

## Problem
Move the first element to the end and shift every other element one position to the left.

## Concept
Save the first element, shift elements left, and place the saved value in the last position.

## Example
```text
Input:
5
1 2 3 4 5
Output:
Rotated array: 2 3 4 5 1
```

## Complexity
Time O(n); extra space O(1), excluding the input array.
