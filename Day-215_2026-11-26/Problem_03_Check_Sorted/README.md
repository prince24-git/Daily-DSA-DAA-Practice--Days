# Problem 3: Check Whether an Array Is Sorted

## Problem
Check whether the given array is sorted in non-decreasing order (each value is at least the previous value).

## Concept
Compare each element with the one immediately before it. If any current value is smaller, the array is not sorted.

## Example
```text
Input:
5
1 3 3 7 9
Output:
Sorted
```

## Complexity
Time O(n); extra space O(1), excluding the input array.
