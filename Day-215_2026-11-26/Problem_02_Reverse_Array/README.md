# Problem 2: Reverse an Array

## Problem
Reverse the order of `n` integers and print the resulting array.

## Concept
Use two pointers: one at the beginning and one at the end. Swap their values, then move both pointers toward the center.

## Example
```text
Input:
5
2 4 6 8 10
Output:
Reversed array: 10 8 6 4 2
```

## Complexity
Time O(n); extra space O(1), excluding the input array.
