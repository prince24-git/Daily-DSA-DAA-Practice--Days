# Problem 6: Check Number Palindrome

## Concept
A non-negative number is a palindrome if it reads the same forward and backward. Reverse its digits and compare with the original.

## Real-life connection
Like checking whether a vehicle number such as 1221 looks the same from either direction.

## Example
```text
Input: 1221
Output: Yes
```

## Input
Input: a non-negative integer.

## Complexity
Time O(d); extra space O(1).
