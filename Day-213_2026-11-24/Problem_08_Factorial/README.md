# Problem 8: Factorial Using a Loop

## Concept
n! is the product 1*2*...*n. By definition, 0!=1. This exercise supports n from 0 through 20 so the result fits in a signed 64-bit integer.

## Real-life connection
Factorials count arrangements; 4 different books can be arranged in 4!=24 orders.

## Example
```text
Input: 5
Output: 120
```

## Input
Input: 0 <= n <= 20 so the answer fits in signed 64-bit integer.

## Complexity
Time O(n); extra space O(1).
