# Problem 7: Check Whether a Number Is Prime

## Concept
A prime number is greater than 1 and has no divisors except 1 and itself. It is enough to test possible divisors up to the square root of n.

## Real-life connection
Prime checks are a basic building block in number theory and cryptography.

## Example
```text
Input: 29
Output: Prime
```

## Input
Input: an integer n.

## Complexity
Time O(sqrt(n)) in the worst case; extra space O(1).
