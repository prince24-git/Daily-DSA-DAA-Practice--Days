# Problem 5: Reverse a Number

## Concept
Take the last digit from n and append it to the reversed value: reversed=reversed*10+n%10. Remove the last digit from n.

## Real-life connection
A simple number palindrome check can compare a number with its reversed digits.

## Example
```text
Input: 1204
Output: 4021
```

## Input
Input: a non-negative integer.

## Complexity
Time O(d); extra space O(1).
