# Problem 4: Count Digits in a Number

## Concept
Repeatedly divide a non-negative integer by 10 and count the steps. Zero is a special case and has one digit.

## Real-life connection
A form may accept an ID only if it has exactly 8 digits; first count the digits.

## Example
```text
Input: 7052
Output: 4
```

## Input
Input: a non-negative integer; zero has one digit.

## Complexity
Time O(d); extra space O(1).
